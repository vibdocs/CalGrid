# CalGrid — Release Notes

## v1.0.6 — 2026-11-21

**Latest stable Windows x64 release**

- First opening of the built-in Docs/Help/Report browser is smoother; webpage clicks work normally.
- Rich message formatting and the template-tag picker are updated.
- Improved dynamic tags, Spintax and per-recipient consistency across event fields.
- Attachment filename personalization and safe naming refinements.
- More reliable recipient import history and app statistics accounting.
- Updated signed-license integration and clean application shutdown.
