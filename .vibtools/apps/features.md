# CalGrid — Google Calendar Invitations

**CalGrid v1.0.6 · Windows 10/11 x64**

Create, personalize and send Google Calendar invitations from your own Google account. CalGrid puts multiple campaigns, connected accounts and progress in one Windows window.

## Features you can use

- **Workspace tabs:** Separate recipients, event details, Google connections, attachments and sending tasks.
- **Google account connection:** Sign in using Google's OAuth browser flow.
- **Events:** Set title, date/time, duration, location or meeting link, and message.
- **Rich message editor:** Bold, italic, underline, strikethrough, lists, links, styles and tag picker.
- **Recipients:** Paste emails or import supported CSV/TXT/Excel lists, remove duplicates and review the count.
- **Personalization:** Insert recipient, brand, date and reference tags; optional Spintax with a live preview.
- **Files:** Add multiple Google Drive attachments and personalize attachment filenames.
- **Branding:** Choose a workspace brand and optional target calendar.
- **Sending:** Safe/Normal/Fast/Ultra pacing, Start/Pause/Resume/Stop, retries and progress counts.
- **Settings:** Timezone, batch size, request pacing, guest privacy, reminders, Meet links and appointment staggering.
- **Help & diagnostics:** Status bar, searchable activity logs, Tags, Docs, Help, Report and About.

## What's improved in v1.0.6?

The embedded Docs/Help/Report browser opens smoothly on first use. Message formatting, per-recipient tags, attachment naming, import accounting, license integration and shutdown reliability have also been updated.
