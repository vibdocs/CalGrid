# System Requirements

CalGrid v1.0.6 supports **Windows 10/11 (64-bit, x64)**.

| Requirement | What you need |
|---|---|
| Computer | Windows 10 or 11 x64 |
| Disk space | At least 650 MB free for the app, plus room for attachments |
| Connection | Internet for license verification, Google sign-in and sending |
| Google | An account with Google Calendar access |
| License | A valid CalGrid license key |
| Installer | PowerShell is optional for automatic installation |

You do **not** need Python or administrator access to run the standard portable app.

macOS, Linux and 32-bit Windows are not supported. Google API quotas and account permissions still apply.
