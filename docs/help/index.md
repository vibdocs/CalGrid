## Reporting Issues

Click **🐛 Report** in the bottom status bar to open the issue reporting page in the built-in browser.

When reporting issues, include:
- CalGrid version (shown in the About dialog or bottom bar)
- Windows version
- A description of what you expected vs. what happened
- The error message (copy from the Debug dialog log)
