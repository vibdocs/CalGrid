# Help & Support

If something does not work, start with the topic closest to your problem.

- [Troubleshooting](troubleshooting.md) — license, Google connection, recipients, attachments and sending
- [Frequently Asked Questions](faq.md) — everyday usage
- [Limits and important notes](limitations.md) — Google quotas, deliveries and privacy
- [Get started](../getting-started/index.md) — install and sign in

In CalGrid, the bottom bar also includes **Docs**, **Help**, **Report** and **Debug**. These open help pages or diagnostics without sending an invitation.

When asking for support, include the CalGrid version, what you clicked and the error message—but **never share a license key, OAuth file, password or access token**.
