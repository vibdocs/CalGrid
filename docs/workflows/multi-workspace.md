# Use Multiple Workspaces

CalGrid can keep several campaigns separate in one window.

1. Select **+ New Workspace** and give it a descriptive name.
2. Connect the Google account for that workspace and configure its event.
3. Add recipients, attachments and an optional brand.
4. Create another workspace for a different event or audience.
5. Switch tabs to review progress without mixing recipient lists.

Each workspace has its own worker and event details. Background jobs may continue while another tab is open, but they still share application-wide pacing safeguards and Google's account/project quotas.

Pause or Stop a job before making major changes. Do not assume closing a tab cancels requests already accepted by Google.
