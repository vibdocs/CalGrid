# Bulk Recipient Import

Use **Upload List** when entering many email addresses.

1. Prepare a clean text, CSV or supported Excel file with recipient email addresses.
2. Select your workspace and choose **Upload List** (or drag a supported file into the recipient area).
3. Let CalGrid finish scanning; the displayed count shows imported recipient emails.
4. Choose **Remove Duplicates**, review the count and remove unwanted addresses.
5. Check the event preview before sending.

Importing a list does not send anything. An incomplete or failed import should not be counted as a successful upload. CalGrid records successful import history for reliable workspace/accounting behavior.

**Tip:** Keep a copy of the original list so you can verify omissions or invalid addresses. Never import addresses you are not authorized to invite.
