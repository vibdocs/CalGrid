# Send Your First Campaign

1. **Activate CalGrid** with your license key.
2. In the left **Google Auth** section, select your Google OAuth JSON if needed and choose **Connect**.
3. Enter a clear **Name**, **Date & Time**, **Meeting Link / Location**, and **Message**.
4. Paste recipient emails or choose **Upload List**. Select **Remove Duplicates**.
5. If desired, add [attachments](../guides/attachments.md), [branding](../guides/brand-identity.md) and [template tags](../guides/template-tags.md).
6. Select a conservative sending **Mode** and choose **Live Preview** to check the final invitation.
7. Select **Start**, then watch **Done / Failed / Left**. Use Pause, Resume or Stop if needed.

For a first run, use a small, appropriate audience that expects the invitation. Respect Google's Calendar quotas and sending policies.

**Remember:** A completed request is not a guarantee of inbox delivery or an accepted invitation.
