# Personalized Invitations

Personalization helps make event details clearer for each recipient.

1. In **Name** or **Message**, add a tag such as `{name}` or `{company}`.
2. Add a reference such as `{ref}` if your workflow needs one.
3. For wording options, use `{spin:Hello|Greetings|Welcome}`.
4. Optionally configure **Brand Name**, **Slot Staggering** or an attachment filename template.
5. Choose **Live Preview** and check several representative recipients before Start.

Supported generated values are kept consistent for one recipient across the event's fields. A generated name may be inferred from an email address rather than the person's actual name—check your content before using it.

Do not put private identifiers in a message unless the recipient should see them.
