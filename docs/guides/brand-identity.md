# Brand Identity

Give a workspace a recognizable name in its Calendar invitations.

1. Select **Brand Name** in the left sidebar.
2. Enter your brand or organization name.
3. If your workflow uses a separate Google Calendar, choose the correct Calendar ID.
4. Save and preview the event title/message.

When enabled, brand details can be included in supported event fields and with the `{brand}` template tag. Each workspace can have different branding.

**Check the target calendar carefully:** Using the wrong calendar ID can cause permission or not-found errors. Branding does not change the Google account or bypass organizer permissions.
