# Workspace Tabs

Workspaces keep different invitations, Google connections and recipient lists separate.

1. Choose **+ New Workspace**.
2. Enter a useful workspace name and set up its Google account, event and recipients.
3. Click any tab to switch tasks. You can rename or close a workspace using its tab controls.
4. Watch each tab's status before leaving or closing a running campaign.

Different tabs may process their own tasks while you work elsewhere, but they share application-level request pacing and are still subject to Google's quotas.

**Tip:** Save a separate workspace for each event, team or audience instead of mixing lists. Closing a workspace while it is sending may require confirmation.
