# Bottom Status Bar

The footer provides quick access to the most-used helpers.

| Button | What it does |
|---|---|
| **Tags** | Opens the template-tag reference |
| **Debug** | Shows log messages and diagnostics |
| **Docs** | Opens the user guide inside CalGrid |
| **Help** | Opens support information |
| **Report** | Opens the issue-reporting page |
| **About** | Shows app/version information |

The footer also shows status and the selected sending mode. **Docs, Help and Report** use CalGrid's built-in browser; opening them does not send invitations.

If a page needs the internet, reconnect and try again. Closing the browser tab returns you to your workspace.
