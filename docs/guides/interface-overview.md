# Interface Overview

CalGrid keeps your work inside one Windows window.

## The main areas

- **Top bar and tabs:** Window controls and workspace tabs. Use **+ New Workspace** to start another task.
- **Left sidebar:** Google Auth (**+ Add**, **Connect / Disconnect**), **Brand Name**, **Event Attachment** and the current **Worker**.
- **Main workspace:** Event title, **Date & Time**, **Meeting Link / Location**, rich **Message**, **Live Preview**, recipients and sending controls.
- **Progress area:** Total, done, failed, remaining and recent activity.
- **Bottom bar:** **Tags**, **Debug**, **Docs**, **Help**, **Report**, **About**, plus current mode/status.

Each workspace can use its own recipient list, message, attachments and connected Google account. The app can keep another workspace running while you switch tabs.

**New in v1.0.6:** Smoother first opening of embedded Help/Docs/Report pages; the license screen remains in the same app window.
