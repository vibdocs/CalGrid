# Event Details

In your workspace, fill out the invitation before you send it.

| Field | What to enter |
|---|---|
| **Name (event title)** | A clear meeting or appointment title |
| **Date & Time** | The planned start date and time |
| **Meeting Link / Location** | A video call link or a place to meet |
| **Message (Description)** | Details guests should read |

## Message editor

Use the toolbar for **bold**, *italic*, underline, strikethrough, bullets, numbering, links and text styles. **Tag** inserts personalized text. Select **Live Preview** to check the final message before sending.

You can use [template tags](template-tags.md) in supported fields and optionally add a [brand identity](brand-identity.md). The effective timezone, duration and automatic Meet-link option come from [Settings](../settings/application-settings.md).

Review time and timezone carefully—different recipients may be in different regions. Fields may be locked during active sending to prevent inconsistent events.
