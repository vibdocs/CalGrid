# Debug & Activity Log

Choose **Debug** in the bottom bar when a Google connection or campaign behaves unexpectedly.

- Review recent events and the running job's status.
- Search or filter messages to find an error.
- Clear old log entries when you no longer need them.
- Compare errors with [Troubleshooting](../help/troubleshooting.md).

Some network errors are temporary; wait or reconnect instead of restarting a campaign blindly. Debug details describe API responses and the application's actions, not proof of inbox delivery.

**Privacy:** Logs may include event or account context. Remove personal details before sharing screenshots or diagnostics with support.
