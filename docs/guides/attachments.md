# Event Attachments

Add files that guests should be able to access with a Calendar event.

1. In the left sidebar choose **Event Attachment** and select your file.
2. Add further files if needed; the workspace lists attached files.
3. Use the adjacent **⚙** button to set an attachment filename template and preview the result.
4. Remove a file from the list if you no longer need it.
5. Preview your event before sending.

CalGrid uses **Google Drive** for attachments. Your Google Cloud project must have the Drive API enabled, and actual file access depends on Google permissions and sharing settings. If Drive access fails, follow the in-app instructions.

Filenames can use [dynamic tags](template-tags.md), including per-recipient values. The app normalizes names for file-system safety; check the preview before a real campaign.

Do not attach sensitive files unless recipients have appropriate access.
